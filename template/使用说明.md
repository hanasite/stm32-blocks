# 使用说明（三步）

1. 用 VSCode 打开本文件夹（File → Open Folder）。
2. 把 ST-Link 和板子接好，板子通电。
3. 按 F5（自动编译 + 烧录 + 调试），或双击「编译烧录.bat」。

## 接线参考

| 外设 | 接法 |
|---|---|
| 按键 | 一端 → PA1，另一端 → GND（配「上拉」） |
| 蜂鸣器（有源，高电平触发款） | 模块 VCC→3V3、GND→GND、信号→PB1 |
| 舵机 | 信号→PA0，VCC→5V，GND→GND（与板子共地） |
| 红外传感器 | 模块 VCC→3V3、GND→GND、OUT→PA2（默认引脚，网页里可改；多数模块为低电平触发） |
| OLED 显示屏（0.96 寸 SSD1306） | 模块 VCC→3V3、GND→GND、SCL→PB8、SDA→PB9（两根接反也能自动识别） |
| 板载 LED | 无需接线（PC13，低电平亮） |

小恐龙游戏是**纯软件组件**：先在网页里建一个「OLED屏」对象和一个「按键/红外」对象，把「运行一帧」积木拖进主循环并在块内绑定（显示到 = OLED、跳跃输入 = 按键/红外），循环里记得加约 30 毫秒延时。跳跃自带 300ms 冷却期。

## 常见问题

- 烧录失败：检查 ST-Link 驱动、SWD 四根线、板子供电。
- 快捷键想换成别的：编译烧录.bat 双击即可。
- 改了 CMakeLists 后编译报 "rebuilding build.ninja" 之类错误：删掉 `build` 文件夹重来一次（本工程禁用自动 regen，避免中文路径崩溃）。
- 工程放在中文文件夹下也能用：构建脚本会自动切到 `C:\` 再调用 cmake（规避 cmake 在中文路径下的已知崩溃）；但能放英文路径更省心。
