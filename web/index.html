新手接线帮助

  

    
1. 面包板的内部构造（记住三条规则）

    
    
    
      
  • 一列 5 孔相连：同一竖列（凹槽上、下各算一列）的 5 个孔内部是通的——元件一只脚插进去，同列任意孔都和它连着。
    • 
      
  • 中央凹槽隔断：凹槽上方和下方互不相通，所以芯片/元件要跨着凹槽插。
    • 
      
  • 电源轨左右断开：红轨（+）和蓝轨（−）在中间都有断点，左半段和右半段不是一回事——所以左右两段要各接一组 3V3 / GND。偷懒办法：红-红、蓝-蓝各飞一根短线跨过中间的断点桥接，就只引一组。
    • 
    

    
2. 先给面包板"通上电"

    
    
      
  • 单片机 3V3 脚 → 面包板红轨；GND 脚 → 蓝轨（左右两段都要，共 4 根线）。
    • 
      
  • 之后所有模块的 VCC 插红轨、GND 插蓝轨，不用每个模块单独往单片机拉两根线。
    • 
      
  • 用 ST-Link 供电时板子就不用再插 USB 了。
    • 
    

    
3. 各模块怎么接

    

      
模块VCCGND信号

      
按键—一端插蓝轨另一端 → PA1（配「上拉」，另一端接 GND）

      
红外传感器红轨 3V3蓝轨OUT → PA2（多数模块低电平触发）

      
LED 小灯珠长脚(+) 串 220Ω 到红轨短脚(−) 接信号脚配「低电平亮，另一端接 3V3」

      
蜂鸣器（有源）红轨 3V3蓝轨信号 → PB1（高电平触发款）

      
舵机接 5V（从板子 5V 脚单独引，别进 3V3 红轨）蓝轨共地信号 → PA0

      
OLED 屏红轨 3V3蓝轨SCL→PB8、SDA→PB9（接反也能自动识别）

      
板载 LED无需接线（PC13，低电平亮）

    

    
4. 下载线（ST-Link → 板子 SWD 四孔）

    
    
      
  • 3V3 → 3V3、GND → GND、SWDIO → PA13、SWCLK → PA14（板子靠内侧的一排 4 个孔，有丝印）。
    • 
    

    
接线口诀：先断电再接；红只进红轨、黑只进蓝轨；插完先检查一遍再上电。拿不准就把积木和接线都截图问学长学姐。
